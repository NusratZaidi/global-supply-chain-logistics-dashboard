📊 Global Logistics & Supply Chain Performance Dashboard
🔹 Project Overview
Built an interactive, executive-level supply chain dashboard in Power BI using a raw dataset of over 180,000+ logistics transactions. The goal was to identify operational inefficiencies, track high-risk delivery locations, and analyze factors contributing to delayed shipments.

🔹 Key Features & Tech Stack
Data Cleaning & ETl: Handled complex date-time syntax errors and multi-format anomalies using Power Query (Advanced regional configurations & custom locale structures).

Data Modeling & DAX: Created optimized calculated columns and dynamic business performance metrics (Total Sales, Total Orders, Late Delivery Rate %).

Advanced AI Visuals: Implemented an interactive Decomposition Tree for dynamic root-cause analysis across different regions, product categories, and shipping methods.

UI/UX Design: Designed an executive glassmorphic dark theme layout with custom slicers for maximum readability and responsive filtering.
